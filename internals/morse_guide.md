# Morse Code Guide

Morse code represents letters and numbers using **dots (`.`)** and **dashes (`-`)**.

## How to Read Morse Code

- `.` = Dot
- `-` = Dash
- A **space** separates letters
- `/` separates words

### Example

```text
..-. --- ... ...
```

| Number |  Code   | Number |  Code   |
