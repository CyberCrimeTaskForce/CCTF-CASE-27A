# ASCII Code Guide

**ASCII** (American Standard Code for Information Interchange) assigns a number to common characters.

In this investigation, numbers may represent characters using their **ASCII decimal values**.

## How to Decode

Take each number and convert it to its corresponding ASCII character.

For example:

```text
70 79 83 83
```

Using the ASCII table:

```text
70 → F
79 → O
83 → S
83 → S
```

**Result: `FOSS`**

```text
A = 65

C = 67
...

```

```text

c = 99
...

```
